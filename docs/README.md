# 项目文档入口

项目文档按用途分为以下几类：

- [场外衍生品法规知识库](../deliverables/场外衍生品法规知识库_20260727.html)：查看当前216份法规，支持搜索、发文主体与收藏筛选、正文阅读、编辑和个人标注。
- [GitHub项目说明与截图清单](guides/GitHub项目说明与截图清单.md)：GitHub 首页的项目叙事、截图拍摄步骤、命名、存放位置和脱敏要求。
- [项目迭代记录](history/项目迭代记录.md)：记录版本变更、变更原因和验证结果；UI 变化配有截图。
- [项目整体逻辑说明](architecture/项目整体逻辑说明.md)：面向业务人员说明从法规原件、Chunk、混合检索到回答的完整逻辑。
- [问答与检索架构](architecture/问答与检索架构.md)：说明 Agent、检索、证据合并、引用校验和 Wiki 的边界。
- [新增法规与知识库十轮迭代记录](history/新增法规与知识库十轮迭代记录_20260724.md)：集中记录正文清洗、Chunk、索引、阅读器、分类表和真实问答链路的验证证据。
- [个人标注同步](guides/个人标注同步.md)：说明如何从Word、PDF导入或嵌入个人批注。
- [评测材料](../evaluation/README.md)：说明200题题库、基线、全量复测和定向迭代结果的目录结构。
- [专家知识 Wiki](../wiki/专家知识Wiki.md)：存放用户确认的业务 Know-how；它不能替代法规原文。

正式数据仍保留在 `data/`：原始监管文件、结构化 JSON、正式 Chunk 和 BM25/向量索引都没有移动。
