# 个人标注同步

安装依赖：

```bash
python3 -m pip install -r scripts/requirements-annotations.txt
```

生成可在HTML中“导入”的JSON：

```bash
python3 scripts/import_local_annotations.py \
  --input "/path/to/annotated-files" \
  --html "deliverables/场外衍生品法规知识库_20260727.html" \
  --output ".cache/personal_annotations_import.json"
```

直接嵌入HTML：

```bash
python3 scripts/import_local_annotations.py \
  --input "/path/to/annotated-files" \
  --html "deliverables/场外衍生品法规知识库_20260727.html" \
  --output ".cache/personal_annotations_import.json" \
  --embed
```

`--embed`会先在HTML同目录生成带时间戳的备份。DOC会通过LibreOffice转换后读取，DOCX直接读取；PDF支持高亮、下划线、删除线、波浪线、文本批注和画笔批注。脚本按文件名匹配法规，未匹配文件会记录在输出JSON的`unmatched`字段。
