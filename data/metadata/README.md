# 法规元数据与分类参考

本目录保留法规目录、分类映射和逐条证据。其中，下列旧版七维分类资产为长期参考数据，不随HTML界面的筛选器简化而删除：

- `viewer_legacy_7d_baseline.json`：旧版七维分类的原始基线；
- `viewer_legacy_7d_classifications.json`：从最终HTML固化的216部入库法规与七个分类维度的映射，共1,613条标签关系；
- `viewer_legacy_7d_evidence.jsonl`：与上述1,613条标签关系一一对应的分类依据、原文定位及官方链接；
- `../../deliverables/场外衍生品法规分类与证据_20260727.xlsx`：便于人工审阅和后续分组设计的审计版Excel。

当前HTML只保留“发文主体”筛选，不代表其他分类维度失效。如需恢复或新增按交易场所、业务品种、客户主体、资金来源、产品载体或交易行为的分组，应优先复用上述映射和证据，并在法规更新后重新核验。

`regulations.jsonl`是当前法规目录主数据；无`legacy_7d`后缀的分类文件供当前构建流程使用。
